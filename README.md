# محصولي | Mahsouli

تطبيق Flutter لاكتشاف القهوة ودليل التحضير — عربي/إنجليزي.

## التشغيل

```bash
flutter pub get
flutter run
```

> مهم على ويندوز: ضع المشروع في مسار قصير (مثل `C:\src\mahsouli`)، لأن المسارات الطويلة
> (أكثر من 260 حرفًا) تُفشل بناء أندرويد.

للتشغيل على جوالك: فعّل "خيارات المطور" ثم "تصحيح USB"، وصِّل الجوال، ثم `flutter run`.
لإنشاء ملف APK للتثبيت: `flutter build apk --release` (الملف في `build/app/outputs/flutter-apk/`).

## هيكل المشروع

| المجلد | المحتوى |
|---|---|
| `lib/main.dart` | نقطة البداية، اللغة، التنقل بين البداية/الدخول/التطبيق |
| `lib/l10n/` | النصوص العربية والإنجليزية + تحويل الأرقام للهندية |
| `lib/models/` | نماذج البيانات (بن، محمصة، وصفة، تقييم، عرض، إشعار، مستخدم) |
| `lib/data/catalog.dart` | بيانات تجريبية: ٦ محامص، ١٠ مناشئ، ١٦ بن، ٩ وصفات، ٦ عروض |
| `lib/state/` | حالة التطبيق والحفظ المحلي (SharedPreferences) + الفلترة |
| `lib/screens/` | جميع الشاشات |
| `lib/widgets/common.dart` | المكونات المشتركة (بطاقة البن، بطاقة الوصفة، التقييم…) |
| `test/app_test.dart` | اختبارات (التسجيل، الدخول، التقييم والنقاط، الاستبدال، البحث، الواجهة) |

## تغطية متطلبات التقرير

- **FR-1** تسجيل حساب، دخول، ضيف، استعادة/تغيير كلمة المرور، تعديل الملف، حذف الحساب
- **FR-2** تصفح البن حسب المحمصة / المنشأ / نوع التحميص والمعالجة
- **FR-3** تفاصيل المنتج: السعر، المنشأ، التحميص، المحمصة، طرق التحضير، الإيحاءات، الارتفاع
- **FR-4** وصفات بالمقادير (قهوة، ماء، طحن، حرارة، خطوات) + حاسبة أكواب/قوة + مؤقت خطوة بخطوة
- **FR-5** تقييم وتعليق على المنتجات والوصفات (تعديل/حذف)
- **NFR-1** بحث بالاسم/المحمصة/المنشأ (يتسامح مع الهمزات والتاء المربوطة)
- **NFR-2** فلترة بالمحمصة، المنشأ، التحميص، السعر، طريقة التحضير، المعالجة، التوفر + ترتيب
- **NFR-3** المحفوظات (بن ووصفات)
- **NFR-4/5** العروض والمكافآت وقسائم الخصم والاستبدال بالنقاط حسب شروط البائع
- **NFR-6** مركز إشعارات مع إعدادات لكل نوع

إضافات: شاشة ترحيب، نقاط ولاء، إضافة وصفاتك الخاصة، نصيحة اليوم، وصفة اليوم، "قد يعجبك أيضًا".
